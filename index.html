Copy your configuration from CPS

In CPS, copy the full configuration, then select Paste from Clipboard. Nothing leaves this browser.

Start a new layout (optional)

Use the pasted codeplug as a base and replace its zones, and optionally its contacts, with a blank layout. Radio settings, voice lists, and site lists are kept. Every generated channel is a new record, so import will ask for its frequencies, contact, and lists before enabling Copy XML.

Zones

Zone names are optional; a blank name becomes Zone 1, Zone 2… Use + Add type to mix channel types in a zone. Channels are numbered CH 01, CH 02… through the whole zone and can be renamed in the workbook.

Contacts

Optional. Choose a contact type to replace the pasted contacts with numbered ones (CP 01, LCP 01, DIG 01…) and sequential Call IDs to rename in the workbook; leave it on None to keep the pasted contacts. Set a starting Call ID for a block (for example 1001), or leave it on Auto to continue from the previous block of that type, starting at 1. Linked Capacity Plus channels use Capacity Plus contacts and share their Call IDs. All Call adds the system's single All Call contact.

Channel Pool

Removes the pasted Channel Pool channels and their frequencies, and empties voice list members that pointed at them. Leave unchecked to keep them.

Channel defaults

Applied to every generated channel that supports the setting. Analog channels have no privacy, RAS, or In Call Criteria, and use Always when Color Code Free is selected. Key aliases must already exist in the target codeplug.

Advanced XML options

Open or save raw CPS XML when you need it. You can also paste XML directly below as a clipboard fallback.

Import your workbook and copy to CPS

Import the workbook you edited, then copy the rebuilt configuration and paste it into CPS.

Builds every Zone Channels and Channel Pool row from its CPS template. Only the settings in the workbook are applied; every other channel setting, such as time slot, transmit power, RX group list, emergency system, and PL tones, resets to the CPS template default. Use it when you are replacing a configuration. Leave it off to edit existing channels and keep their other settings.
