Copy your configuration from CPS

In CPS, copy the full configuration, then select Paste from Clipboard. Nothing leaves this browser.

Start a new zone layout (optional)

Use the pasted codeplug as a base and replace its zones with a blank layout. Radio settings, contacts, Channel Pool, voice lists, and site lists are kept. Every generated channel is a new record, so import will ask for its frequencies, contact, and lists before enabling Copy XML.

Zone names are optional; a blank name becomes Zone 1, Zone 2… Use + Add type to mix channel types in a zone. Channels are numbered CH 01, CH 02… through the whole zone and can be renamed in the workbook.

Channel defaults

Applied to every generated channel that supports the setting. Analog channels have no privacy, RAS, or In Call Criteria, and use Always when Color Code Free is selected. Key aliases must already exist in the target codeplug.

Advanced XML options

Open or save raw CPS XML when you need it. You can also paste XML directly below as a clipboard fallback.
